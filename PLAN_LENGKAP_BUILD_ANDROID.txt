2. Download: Windows x64 .msi installer

4. Path default: C:\Program Files\Eclipse Adoptium\jdk-17.x.x-hotspot

OPSI C: Oracle JDK 17 (Requires Oracle account)
------------------------------------------------------------
1. Buka: https://www.oracle.com/java/technologies/downloads/#java17

3. Login dengan Oracle account (gratis, tapi perlu registrasi)

LANGKAH 5: DEPLOY SUPABASE EDGE FUNCTION (Untuk Push Notification)
================================================================================

KENAPA PERLU:
- Edge Function menerima webhook dari database saat ada laporan baru
- Edge Function mengambil semua FCM tokens dari tabel ews_fcm_tokens
- Edge Function mengirim push notification ke semua device Android

CARA DEPLOY:

1. Install Supabase CLI (jika belum ada):
   
   npm install -g supabase

2. Login ke Supabase:
   
   supabase login
   
   (Browser akan terbuka, authorize Supabase CLI)

3. Link project lokal ke Supabase project:
   
   cd "C:\Users\ADMIN OS\Desktop\sip3"
   supabase link --project-ref YOUR_PROJECT_REF
   
   Ganti YOUR_PROJECT_REF dengan ref project Anda
   (Lihat di URL Supabase Dashboard: https://supabase.com/dashboard/project/YOUR_PROJECT_REF)

4. Deploy Edge Function:
   
   supabase functions deploy kirim-notif-ews

5. Set Secrets (Environment Variables):
   
   # Firebase Project ID (lihat di Firebase Console → Project Settings)
   supabase secrets set FIREBASE_PROJECT_ID=sip-rt004-jatimulya
   
   # Firebase Access Token (untuk development, berlaku ~1 jam)
   # Cara dapat token:
   firebase login:ci
   # Copy token yang muncul
   
   supabase secrets set FIREBASE_ACCESS_TOKEN="1//0abcdef...xyz"

6. Verifikasi secrets tersimpan:
   
   supabase secrets list

CATATAN FIREBASE ACCESS TOKEN:

Token dari firebase login:ci berlaku ~1 jam saja (untuk development/testing).

Untuk PRODUCTION (jika app sudah stabil):
- Download Service Account JSON dari Firebase Console
- Gunakan library google-auth-library untuk generate token programmatically
- Lihat dokumentasi lengkap di: supabase/functions/kirim-notif-ews/README.md

UNTUK TESTING AWAL (1-2 minggu):
- Gunakan firebase login:ci sudah cukup
- Jika token expired (push notif tidak masuk), generate token baru dengan firebase login:ci
- Update secret: supabase secrets set FIREBASE_ACCESS_TOKEN="token_baru"

LANGKAH 6: SETUP DATABASE WEBHOOK DI SUPABASE
================================================================================

KENAPA PERLU:
- Webhook trigger Edge Function setiap kali ada INSERT baru ke tabel ews_laporan_rt004
- Tanpa webhook, Edge Function tidak akan jalan, push notification tidak terkirim

CARA SETUP (Via Supabase Dashboard - RECOMMENDED):

1. Buka Supabase Dashboard:
   https://supabase.com/dashboard

2. Pilih project Anda

3. Klik "Database" di menu kiri

4. Klik "Webhooks" (sub-menu di bawah Database)

5. Klik "Create a new hook" atau "Enable Webhooks"

6. Isi form:
   
   Name: webhook_kirim_notif_ews
   
   Table: ews_laporan_rt004
   
   Events: ☑ Insert (centang Insert saja, uncheck Update/Delete)
   
   Type: HTTP Request
   
   Method: POST
   
   URL: https://YOUR_PROJECT_REF.supabase.co/functions/v1/kirim-notif-ews
   (Ganti YOUR_PROJECT_REF dengan ref project Anda)
   
   HTTP Headers:
   {
     "Content-Type": "application/json",
     "Authorization": "Bearer YOUR_ANON_KEY"
   }
   
   (Ganti YOUR_ANON_KEY dengan anon key project Anda)
   (Lihat di: Settings → API → Project API keys → anon public)

7. Klik "Create webhook"

VERIFIKASI WEBHOOK BERHASIL:

1. Test manual dengan INSERT SQL:
   
   Buka SQL Editor, jalankan:
   
   INSERT INTO ews_laporan_rt004 (jenis_kejadian, deskripsi, nama_pelapor, alamat, status)
   VALUES ('KEBAKARAN', 'Test webhook', 'Admin Test', 'Jl. Test No. 1', 'BARU');

   PENTING: nilai jenis_kejadian dan status HARUS HURUF BESAR.
   Kode frontend (src/types.ts) memakai:
   - jenis_kejadian: KEBAKARAN | BANJIR | KECELAKAAN | KRIMINALITAS | MEDIS | LAINNYA
   - status: BARU | DITANGANI | SELESAI
   Jika diisi huruf kecil, data tetap masuk ke database tapi dashboard admin
   tidak bisa menampilkan label/warna dengan benar.

2. Cek logs Edge Function:
   
   supabase functions logs kirim-notif-ews --tail
   
   Harus muncul log:
   [kirim-notif-ews] Received webhook: {...}
   [kirim-notif-ews] FCM tokens found: X
   [kirim-notif-ews] FCM send result: {...}

3. Jika log muncul dan tidak ada error, webhook berhasil!

TROUBLESHOOTING WEBHOOK:

ERROR: Edge Function tidak terpanggil (tidak ada log)
SOLUSI: 
- Cek URL webhook sudah benar (https://PROJECT_REF.supabase.co/functions/v1/kirim-notif-ews)
- Cek Authorization header sudah ada
- Cek event Insert sudah dicentang

ERROR: "unauthorized" di logs
SOLUSI: 
- Anon key di Authorization header salah
- Update webhook, ganti dengan anon key yang benar

ERROR: "FIREBASE_PROJECT_ID not found"
SOLUSI:
- Secret belum di-set
- Jalankan: supabase secrets set FIREBASE_PROJECT_ID=your-project-id

LANGKAH 8: BUILD APK RELEASE (Untuk Distribusi)
================================================================================

KENAPA PERLU APK RELEASE:
- APK debug ukurannya lebih besar (~15-20 MB)
- APK release lebih kecil dan optimized (~8-12 MB)
- APK release harus di-sign dengan keystore (seperti "stempel digital")

CARA BUILD APK RELEASE:

STEP 8.1: Generate Keystore (Sekali Saja)
------------------------------------------------------------
1. Buka Command Prompt

2. Generate keystore:
   
   keytool -genkey -v -keystore sip-rt004-release.keystore -alias sip-rt004 -keyalg RSA -keysize 2048 -validity 10000
   
3. Isi pertanyaan:
   
   Keystore password: [Buat password kuat, CATAT BAIK-BAIK!]
   Re-enter password: [Ulangi password]
   
   What is your first and last name? RT 004 Jatimulya
   What is your organizational unit? RT 004
   What is your organization? Kelurahan Jatimulya
   What is your City/Locality? Bekasi
   What is your State/Province? Jawa Barat
   What is two-letter country code? ID
   
   Is CN=RT 004 Jatimulya, OU=RT 004, ... correct? yes
   
4. File sip-rt004-release.keystore akan dibuat di folder saat ini

5. PINDAHKAN keystore ke folder project:
   
   move sip-rt004-release.keystore "C:\Users\ADMIN OS\Desktop\sip3\"

PENTING SEKALI:
- BACKUP file sip-rt004-release.keystore ke tempat aman (USB, cloud)
- CATAT password dengan aman (password manager)
- Jika keystore hilang, TIDAK BISA update app di masa depan!
- User harus uninstall app lama, install app baru (data hilang)

STEP 8.2: Konfigurasi Signing di Gradle
------------------------------------------------------------
1. Buat file keystore.properties di folder android/:
   
   Buka Notepad, buat file baru dengan isi:
   
   storePassword=PASSWORD_KEYSTORE_ANDA
   keyPassword=PASSWORD_KEYSTORE_ANDA
   keyAlias=sip-rt004
   storeFile=../../sip-rt004-release.keystore
   
   (Ganti PASSWORD_KEYSTORE_ANDA dengan password yang dibuat tadi)
   
   Save as: C:\Users\ADMIN OS\Desktop\sip3\android\keystore.properties

2. Edit file android/app/build.gradle:
   
   Buka: C:\Users\ADMIN OS\Desktop\sip3\android\app\build.gradle
   
   Cari baris:
   android {
       ...
   }
   
   TAMBAHKAN di ATAS baris "android {":
   
   def keystorePropertiesFile = rootProject.file("keystore.properties")
   def keystoreProperties = new Properties()
   if (keystorePropertiesFile.exists()) {
       keystoreProperties.load(new FileInputStream(keystorePropertiesFile))
   }
   
   TAMBAHKAN di DALAM "android {", sebelum "buildTypes":
   
   signingConfigs {
       release {
           keyAlias keystoreProperties['keyAlias']
           keyPassword keystoreProperties['keyPassword']
           storeFile keystoreProperties['storeFile'] ? file(keystoreProperties['storeFile']) : null
           storePassword keystoreProperties['storePassword']
       }
   }
   
   UBAH "buildTypes { release { ... } }":
   
   buildTypes {
       release {
           signingConfig signingConfigs.release
           minifyEnabled false
           proguardFiles getDefaultProguardFile('proguard-android-optimize.txt'), 'proguard-rules.pro'
       }
   }

3. Save file build.gradle

STEP 8.3: Build APK Release
------------------------------------------------------------
1. Buka Command Prompt

2. Set JAVA_HOME:
   
   $env:JAVA_HOME="C:\Program Files\Microsoft\jdk-17.0.13"

3. Build APK Release:
   
   cd "C:\Users\ADMIN OS\Desktop\sip3\android"
   .\gradlew.bat assembleRelease

4. Tunggu proses selesai (~5-10 menit)

5. APK Release ada di:
   
   C:\Users\ADMIN OS\Desktop\sip3\android\app\build\outputs\apk\release\app-release.apk
   
   Size: ~8-12 MB (lebih kecil dari debug)

6. RENAME APK agar mudah dikenali:
   
   copy "app\build\outputs\apk\release\app-release.apk" "C:\Users\ADMIN OS\Desktop\SIP-RT004-v1.0.0.apk"

TROUBLESHOOTING BUILD RELEASE:

ERROR: "Keystore file not found"
SOLUSI: Cek path storeFile di keystore.properties
        Pastikan file sip-rt004-release.keystore ada di C:\Users\ADMIN OS\Desktop\sip3\

ERROR: "Incorrect keystore password"
SOLUSI: Password di keystore.properties salah
        Cek ulang password, pastikan tidak ada spasi

ERROR: "Failed to read key"
SOLUSI: keyAlias salah, pastikan: keyAlias=sip-rt004

   - Package name sama (id.go.bekasi.jatimulya.rt004)
   - Ditandatangani dengan keystore yang sama
   - versionCode lebih besar dari versi sebelumnya
